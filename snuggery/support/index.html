Snuggery: Mini-Apps, for iPhone

Snuggery is a private home for the mini-apps and files you make with AI. It is offline by default and goes online only where you choose. Your files stay on your device — there is no account to lose access to and no server to be down.

Common questions

A mini-app I imported shows a blank screen

It is almost always trying to load something from the internet — a font, a chart library, an image on a server. Mini-apps in Snuggery run fully offline and cannot make network requests, by design. Ask your AI to rebuild it with everything included in the ZIP and no external links.

My ZIP was refused

Snuggery inspects an archive before extracting anything, and refuses structures that are unsafe or unreasonably large. The message tells you which check failed. Most often the fix is to ask your AI for a plain ZIP of the app's files. (One folder wrapping everything is fine; a ZIP with no index.html at its top level is not refused, but comes in as a folder, and the message names the file to move.)

Can I edit the data my apps use?

Yes — that is the point. Open a mini-app, tap ⋯, then App Files. Edit a .csv or .json file there and the app shows your change the next time it reads it. Try it with Run Tracker's runs.csv. If Snuggery fetches that file from a connection, its next fetch replaces your edit.

How do I get my work out?

Any item can be exported as a ZIP at any time, whether or not you have bought Snuggery: touch and hold its row in the Library (or swipe the row left) and choose Export. Nothing you make is ever locked inside the app. To take the whole library at once — and to bring it back — use Settings → Backup instead; see “I got a new phone”.

My AI gave me a new version of a mini-app — how do I update it?

Touch and hold the app's row in the Library and choose Replace with a ZIP, then pick the new ZIP. Snuggery asks whether to Keep Saved Data or Start Fresh: keeping it means the new version opens with everything the old one had stored — a tracker's entries, its settings — because the app itself is the same item, only its code changed.

Importing the new ZIP instead makes a second app beside the first, and it starts empty: what an app saves belongs to the item it was saved in. If you have already done that, replace the original and delete the copy.

I got a new phone

Purchases restore through Settings → Restore Purchases.

For everything else, the reliable way is Snuggery's own backup: Settings → Backup → Back Up Everything writes a single .snuggery file holding your whole library — every file, folder and mini-app, and on iOS 26 or later what each mini-app has saved. Keep it somewhere other than the phone. On the new phone, Settings → Restore from a Backup puts it all back; the Library's empty screen offers the same thing. Restoring replaces whatever is in the library at the time, and it tells you what the backup holds before it does.

A backup carries each connection's address, never its key. After a restore, Snuggery fetches nothing for an app until you confirm its connection on that app's Keep This Up To Date screen; background refresh and notifications are off again, and a Rebuild Data job comes back by name only, to set up again. On a new phone, sign in to GitHub again first.

Your files and folders also travel with an encrypted device backup or a direct device-to-device transfer. The records a mini-app keeps for itself (a tracker's entries, say) are stored by iOS's web engine, which only adds them to a device backup once you have reopened that mini-app a day or more after first using it — which is the gap Snuggery's own backup closes.

Snuggery will put one quiet line in your Library if it has been more than two weeks since your last backup and something has changed since then — never a notification, never a badge, and Settings → Remind Me to Back Up turns it off for good.

Backups are named “Snuggery Backup” and the date, so they sort by age wherever you keep them, and the restore browser shows only backups and ZIP files rather than everything on your phone. Two backups on the same day are offered the same name; your phone asks what to do about that, and Snuggery never replaces a file itself.

Two things it does not do, said plainly: below iOS 26 it carries the files but not what mini-apps saved — and a backup made on iOS 26 cannot put that data back on an older phone either, though the files still come back. It never carries data an app kept in IndexedDB rather than local storage. Snuggery tells you which of those applies, both when you make a backup and before you restore one.

Does Snuggery go online?

Only where you choose. Until you set up a connection, Snuggery makes no network requests of its own. A connection is a web address you give a mini-app, on its Keep This Up To Date screen, so that Snuggery can fetch that app's data file when you open the app, when you come back to it, and from the ↻ button's Get New Data — and, only for an app you turn it on for, now and then in the background and when a Shortcuts automation of yours runs Refresh a Snuggery App. You can also sign in to GitHub to reach a private repository of yours. One sign-in covers all your apps, and Choose from GitHub… helps you find the data file. Each connection is approved once, listed under Settings → Connections, and can be removed there at any time. Mini-apps themselves never reach the internet. The privacy policy says exactly what is sent, and to whom.

Snuggery never asks you to enter a code someone else sent you. Signing in to GitHub shows a short code in Snuggery for you to type on GitHub's own page. If a code reaches you by message, email or a call, it is someone else's sign-in: don't enter it.

How do I refresh an app?

The ↻ button in an app's toolbar has Reload (start the app again from its files), Get New Data (when the app has a data address) and Rebuild Data (when you set up a GitHub workflow, a web address that starts your job, or a shortcut to rebuild it). For a GitHub workflow, Rebuild Data runs it, waits for it to finish, then fetches the result; for a web address, it sends the request, and you tap Get New Data once the job is done; for a shortcut, it opens Shortcuts to run the one you set up.

Why won't a work file open?

If your organization protects its files with Microsoft Intune app protection, a file saved from its apps is encrypted, and only your organization's apps can open it. Snuggery says so rather than showing the scrambled bytes. Save the file from an app that isn't managed, or ask your IT team.

Can an app send me notifications?

Only if you turn on Notifications for it on its Keep This Up To Date screen. Snuggery then shows the alerts listed in that app's own data file, at most three at once and six a day, with the app's name on each. Restoring a backup turns them off again.

Do I need a subscription?

No. Snuggery is one payment, once. You get the complete app free for seven days first, and when the trial ends, everything already in your library stays openable and exportable. Adding new things, Ask, and fetching new data for your apps then need the purchase; removing a connection never does.

Does Snuggery build the apps for me?

No. Snuggery writes a prompt you paste into your own AI — Claude, ChatGPT, or any other — and imports and runs what comes back. The building happens in the AI you already use.
