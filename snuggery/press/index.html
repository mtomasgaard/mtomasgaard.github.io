Press

The facts, the clips and the screenshots — use any of it.

Snuggery: Mini-Apps — Snuggery for short — is an iPhone app for the small apps people build by asking an AI. Ask for a training log, a recipe box or a dashboard and you get a folder of HTML with nowhere to run it on a phone; Snuggery is where it lives. Import the ZIP, tap it, it runs — offline, in a sandbox that cannot reach the network, beside the user's PDFs, notes and spreadsheets. Apps read the data files stored next to them, which the user can edit in place. It imports many apps at once — several ZIPs picked together, several files shared together, or one bundle of example apps — and offers newer versions of the examples that come with it. Since 1.3, Snuggery itself can fetch an app's data file from an address the user approves; the mini-apps stay offline. Made by one developer in Norway. One purchase after a free week.

The facts

  • Name: Snuggery: Mini-Apps on the App Store, with the subtitle Run the apps your AI builds; Snuggery on the home screen.
  • Platform: iPhone, iOS 18 and later. Ask needs a phone with Apple Intelligence (iOS 26).
  • Price: one purchase after a complete 7-day trial. No subscription, no account. When the trial ends, adding new content, Ask and connections (setting one up, and every fetch) are gated; everything already imported keeps opening and can always be exported, and removing a connection is never gated.
  • What it does not do: generate apps. Its Create tab writes a prompt for the user's own AI; the ZIP that comes back is what gets imported. The app contacts no AI service.
  • Privacy: no account, no analytics, no third-party frameworks. Offline by default: the app makes network requests of its own only for a connection the user sets up and approves (a data file's address, or their own GitHub repository), and nothing goes to the developer (GitHub does show the owner of Snuggery's GitHub App which accounts installed it). Mini-apps are blocked from the network by a WebKit content rule list, a Content-Security-Policy header and the navigation policy, independently, and there is no JavaScript-to-native bridge. Everything but a connection and the examples page works in Airplane Mode; you can check. The privacy policy says what is sent and to whom, in about five minutes' reading.
  • App Review: every version so far approved by App Review; the review note makes the guideline 4.7 (HTML5 mini apps) case explicitly — the app distributes nothing; every mini-app is a file the user imported, the way a document viewer holds documents.
  • Data files: mini-apps read the data files stored beside them — a .csv or a .json the user can edit in place, or keep up to date on a schedule of their own (how the developer's own training dashboard does it). Snuggery can also fetch an app's data file itself, from an address the user approved, and start their own GitHub job with Rebuild Data; mini-apps themselves never go online.
  • The examples: nineteen apps in an open template repository, all built by asking an AI — a 3D mountain from Kartverket's open terrain, the Norne oil-field reservoir model, two atlases of the North Sea's and the world's oil and gas, the galaxy from JPL and Gaia data, a human body in 1,752 parts, a Garmin dashboard, an original kart racer. They run in a browser too.
  • Built with: Apple frameworks only — SwiftUI, SwiftData, WebKit, StoreKit 2, App Intents, BackgroundTasks, UserNotifications, Security and, for Ask, Foundation Models; no third-party code. Mini-apps are served over a custom URL scheme whose handler is a static file server for one package directory, each app with its own origin; ZIP import inspects every entry before extracting and is bounded by absolute limits, never compression ratios.
  • App Store: apps.apple.com/app/id6805883209
  • Contact: mtomasgaard+snuggery@gmail.com — codes for the purchase on request.
