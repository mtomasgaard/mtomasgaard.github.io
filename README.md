# mtomasgaard.github.io

The public support and privacy pages for my apps, served by GitHub Pages.

| Path | Page |
| --- | --- |
| `/snuggery/` | Snuggery — landing |
| `/snuggery/support/` | Snuggery — Support URL given to App Store Connect |
| `/snuggery/privacy/` | Snuggery — Privacy Policy URL given to App Store Connect |

**These pages are generated from the app's own repository.** The source of truth for
everything under `/snuggery/` is `Site/` in the private Snuggery repo — edit there and
copy across, so the privacy text cannot drift from what the app actually does.

Plain HTML and one stylesheet. No build step, no Jekyll, no dependencies.
